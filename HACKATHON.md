## SpeakBro submission positioning

**Project:** SpeakBro — a local-first voice agent control room
**Track:** **Theme 2 — UX for Agentic Applications**
**One-line pitch:** SpeakBro makes an agent observable and interruptible: people can see what it is doing, inspect OpenCode work, understand memory decisions, and stay in control of every turn.

### Why it fits Theme 2

SpeakBro is deliberately an interface layer rather than another hidden chatbot. The control room gives the user:

- a live transcript and agent activity surface for steering the current turn;
- connection, trust, and guardrail signals that explain whether it is safe to continue;
- OpenCode session supervision with active/idle grouping, selection, transcript inspection, and diff summaries;
- a durable memory review surface showing what was saved, skipped, and why;
- interruption and project-selection controls so the user can stop or redirect work without losing context.

### Judge-ready demo path (3 minutes)

1. Open the **Control room** and point out the live connection and trust indicators.
2. Send a short text request; show the transcript, working status, and activity banner.
3. Select an OpenCode session, open its detail view, and inspect the transcript and diff summary.
4. Return to the control room and interrupt a spoken response to demonstrate human override.
5. Open **Memory** and show a saved/skipped decision with its reason and the live audit trail.
6. Close by explaining the product thesis: *agents can move quickly without becoming unaccountable.*

Themes & Problem Statements
Themes 1–5 are OpenAI’s five official Codex build directions. Themes 6–9 are India-relevant bonus themes. Each track carries ten ranked project ideas in the accompanying "Themes & Project Ideas" document-you may pick one of those, remix them, or bring your own idea within the track.

1. Agentic Coding
   The core of Codex - agents that write, refactor, test and ship code.
   Example ideas: Auto-docs agents, commit & changelog agents, test-coverage agents, dependency-upgrade bots, framework migrations, security-review agents, multi-agent engineering teams, self-healing CI.
2. UX for Agentic Applications
   The interface layer -how humans steer, review and trust agents.
   Example ideas: Agent activity logs, one-click diff review, multi-agent supervisor dashboards, trust meters, IDE extensions that pause/fork a running agent, natural-language agent debuggers.
3. Multimodal Intelligence
   Codex plus vision, audio and data.
   Example ideas: Screenshot-to-code, voice-to-app, wireframe-to-deployed-app, whiteboard-photo to schema + CRUD API, architecture diagram to scaffolded microservices, video tutorial to runnable repo.
4. Domain Agents
   Codex applied to a specific vertical's real workflow.
   Example ideas: Fintech expense categorisers, legal clause explainers, healthcare intake agents, logistics route + ETA agents, tax-filing agents, continuous compliance auditors.
5. Building Evals
   Reliability and measurement - increasingly emphasised at Codex events.
   Example ideas: Agent test harnesses, prompt-regression trackers, red-team evals, hallucination detectors for code agents, long-horizon reliability benchmarks, cost/latency/quality dashboards.
6. AI Agents for Bharat's Businesses
   BFSI, retail and MSME automation.
   Example ideas: WhatsApp invoicing for kirana stores, GST reminder agents, inventory + reorder agents, bilingual D2C support, "MSME back-office in a box", UPI reconciliation across messy real-world data.
7. Vernacular / Indic Languages & Local Discovery
   "Solve for India" -language, mobility and local discovery.
   Example ideas: Code-comment translation, vernacular error explainers, voice-to-app in Hindi/Tamil/Bengali, civic query agents, government-service integration layers, Indic-language coding tutors.
8. AI for Societal Good
   Healthcare, accessibility, disaster response and civic tech.
   Example ideas: Accessibility agents (alt-text, ARIA, captions), disaster-info aggregators, clinic triage routing, municipal budget explainers, road-safety appraisal from dashcam or satellite imagery.
9. Vibe Coding / Games / Creative
   Fun, weird and delightful - for non-traditional builders.
   Example ideas: Browser mini-games built in an hour, meme-to-web-app generators, AI dungeon masters, generative music visualisers, games that rewrite their own rules at runtime.
